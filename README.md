# BlinkIT Grocery Sales Dashboard

## Project Overview
Interactive Power BI dashboard analyzing BlinkIT grocery sales, outlet performance, product trends, and customer ratings.

## Tools Used
- Power BI
- DAX
- Data Visualization

## Dashboard Pages
1. Overview Dashboard
2. Outlet Analysis
3. Product Analysis
4. Executive Summary

## Key Insights
- Low Fat products contribute the highest sales.
- Fruits & Vegetables are the top-selling category.
- Tier 3 outlets generate the highest sales.
- Average customer rating is 3.92.
